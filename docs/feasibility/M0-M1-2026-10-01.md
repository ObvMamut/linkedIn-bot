## Implementation and validation

M1 establishes Python 3.14.7, uv 0.10.2, `pyproject.toml`, `uv.lock`, a packaged CLI,
Pydantic strict contracts, TOML validation, a single SQLite worker, versioned SQL migrations,
UUID profile/fact/action/artifact identities, fact/preferences/action revisions, immutable
action snapshots, exact-digest invalidation, draft-only policy, persisted blocked proposals,
crash recovery, durable work claims/checkpoints/retry budgets, pause and sleep coalescing,
OS-held runtime locks, redacted structured console logs, immutable artifact manifests, and
manual consistent backup/restore.

The runtime has no employer-facing effect adapter. Intent/attempt/reservation tables and
recovery are implemented and tested with injected crash states; actual quota reservation,
approval consumption, dispatch, and reconciliation workflows belong to M5. No claim of
exactly-once external delivery is made. Generated personal material and semantic fact
validation remain M4; immutable storage is their foundation.

Restore verifies private snapshot checksums, schema/app compatibility, database integrity,
foreign keys, and artifact manifests. It requires a fresh target directory, retains original
state, starts paused/draft-only with audit required, invalidates approvals, and moves restored
ready/executing actions to unknown. Automatic daily backups and retention remain part of
the later continuous lifecycle; manual backup/restore foundations are usable now.

The approved live CLI demonstration used only `/tmp/linkedin-bot-m1-live`:

```sh
uv run linkedin-bot --data-dir /tmp/linkedin-bot-m1-live collect greenhouse astranis --limit 20
uv run linkedin-bot --data-dir /tmp/linkedin-bot-m1-live collect lever verygoodsecurity --limit 20
```

Results: 20 + 19 + 20 = 59 public observations persisted in real SQLite, three completed
one-shot records, zero unknown effects, zero outbound caps, no recurring work, and a
successfully created private database/artifact-manifest backup. No candidate facts were
invented. Temporary local evidence is not a production user installation.
